### 3. 数据限制检查功能 ✅

**新增模块：`utils/data_limits.py`**

功能：
- 检查不同交易所的数据可用性限制
- 支持 Binance（OI: 21天）和 OKX（OI: 90天）
- 在配置构建时自动检查并警告用户
- 提供推荐的日期范围

示例输出：
```
⚠️ 数据范围 29 天超过 BINANCE OI 数据限制 (21 天)。
建议：
  1. 缩短日期范围至 21 天以内
  2. 使用 OKX 交易所（限制更宽松）
  3. 分段获取数据
```
