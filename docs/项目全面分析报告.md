  三、关键问题

  🔴 严重问题

  1. main.py职责过重（998行）

  问题： 单文件承担7大职责
  main.py:998行
  ├── 数据验证（556-787行）
  ├── 数据获取（44-69行）
  ├── 策略依赖检查（72-223行）
  ├── OI/Funding管理（226-412行）
  ├── 工具更新（937-968行）
  ├── 文件清理（970-977行）
  └── 回测执行（979-991行）

  影响：
  - 可维护性差
  - 测试困难
  - 职责不清

  建议： 拆分为独立模块
  data/validator.py - 数据验证
  data/fetcher_manager.py - 数据获取管理
  strategy/dependency_checker.py - 策略依赖检查

  2. 配置系统双轨制

  问题： 新旧配置系统并存
  # 旧系统
  config/definitions.py - LegacyStrategyConfig
  # 新系统
  config/schemas.py - StrategyConfig (Pydantic)
  config/manager.py - ConfigManager

  影响：
  - 代码混乱
  - 学习曲线陡峭
  - 维护成本高

  建议：
  - 选项A：完成迁移到新系统（推荐）
  - 选项B：明确保留原因并文档化

  3. 数据获取限制未明示

  问题： Binance OI数据仅21天
  # utils/data_retrival.py:186-190
  if oldest_ts > start_ms:
      print(f"⚠️ Warning: Requested data from {datetime...},
            but API only provides recent ~21 days")

  影响：
  - 用户配置长时间回测会失败
  - 错误信息不明显
  - 数据不完整导致回测结果不可靠

  建议：
  # 在配置验证阶段检查
  def validate_oi_data_availability(start_date, end_date, exchange):
      if exchange == "binance":
          max_days = 21
          if (end_date - start_date).days > max_days:
              raise ConfigValidationError(
                  f"Binance OI data limited to {max_days} days. "
                  f"Use OKX or adjust date range."
              )

  影响：
  - 数据获取慢
  - 资源利用率低

  import asyncio
  import aiofiles

  async def batch_fetch_ohlcv_async(...):
      tasks = [fetch_ohlcv_async(symbol) for symbol in symbols]
      results = await asyncio.gather(*tasks)

  五、性能优化建议

  1. 数据加载优化

  # 当前：同步加载
  df = pd.read_csv(path)  # 阻塞

  # 优化：异步+缓存
  @lru_cache(maxsize=100)
  async def load_csv_cached(path):
      return await asyncio.to_thread(pd.read_csv, path)

  2. 并行数据获取

  # 当前：串行
  for symbol in symbols:
      fetch_data(symbol)  # 串行

  # 优化：并行
  with ThreadPoolExecutor(max_workers=10) as executor:
      futures = [executor.submit(fetch_data, s) for s in symbols]
      results = [f.result() for f in futures]

  3. 内存优化

  # 使用生成器减少内存占用
  def load_bars_generator(file_path):
      for chunk in pd.read_csv(file_path, chunksize=10000):
          yield from process_chunk(chunk)
